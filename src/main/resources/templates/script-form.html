Upload

Unique identifier shown across the dashboard.
Comma-separated, used for filtering.
Declare CLI arguments so the Run form renders input fields. Fields: name, label, required, defaultValue, description.
— leave empty to keep the current file. Supported: .py .sh .ps1 .bat .cmd
Cancel

Examples

Parameters JSON:

[
  {
    "name": "username",
    "label": "Username",
    "required": true,
    "description": "User to provision"
  },
  {
    "name": "shell",
    "label": "Default shell",
    "required": false,
    "defaultValue": "/bin/bash"
  }
]
