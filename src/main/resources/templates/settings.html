Requires SMTP configured via AUTORUN_SMTP_HOST / AUTORUN_SMTP_USERNAME / AUTORUN_SMTP_PASSWORD.

How alerts work

  • Each script run / job carries a Notify on policy: FAILURE, ALWAYS or NEVER.
  • On failure, both channels fire if enabled.
  • Email body includes status, exit code, duration and the log file path.
  • Slack posts a formatted message to your webhook.
